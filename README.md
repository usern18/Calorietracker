# Лабораторна робота 1 та 2: Реалізація консольного застосунку мовою Java

## Предметна область
Тема проєкту: **Облік спожитих калорій**.
У програмі реалізовано сутність **«Прийом їжі / Страва»** (`Food`), яка описується п'ятьма характеристиками різних типів:
- `mealName` (`String`) — назва страви.
- `weightGrams` (`double`) — фактична вага порції у грамах.
- `caloriesPer100g` (`double`) — енергетична цінність на 100 грамів продукту.
- `proteinPer100g` (`double`) — вміст білків на 100 грамів продукту.
- `mealTypeInt` (`int`) — числовий код типу прийому їжі (1-4).

## Лабораторна робота №2. Опрацювання масивів із застосуванням циклів

### Функціонал та реалізовані рівні:
* **Базовий рівень:** Створення масиву об'єктів класу `Food`, заповнення з клавіатури за допомогою `Scanner` у циклі `for`, виведення через цикл `for-each`, перезначення методу `toString()` та підсумок елементів за умовою (підрахунок кількості страв із загальною калорійністю понад 400 ккал).
* **Середній рівень:** Ручна реалізація сортування масиву об'єктів методом простого обміну (**Bubble Sort**) за загальною калорійністю без використання вбудованих засобів (`Arrays.sort`). Виведення масиву до і після сортування.
* **Високий рівень:** Лінійний пошук ідентичного об'єкта в масиві за зразком через перевизначений метод `equals()`.

## Лабораторна робота №3. Реалізація обробки винятків та створення власних підкласів Exception

### Мета
Застосувати механізм обробки виняткових ситуацій (`try-catch-finally`, `throw`), навчитися розрізняти типи стандартних винятків та створювати власні (custom) підкласи `Exception`, застосувати ці навички у валідації даних предметної області обліку калорій.

### Реалізовано (Рівень 3 — Високий)

#### 1. Ієрархія власних checked-винятків
- `DomainException` — базовий клас (extends `Exception`)
- `InvalidWeightException` — некоректна вага порції (≤ 0)
- `InvalidCaloriesException` — від'ємна калорійність
- `InvalidMealTypeException` — тип прийому їжі поза діапазоном 1–4

Кожен підклас зберігає додаткову інформацію про некоректне значення (`invalidValue`).

#### 2. Валідація в конструкторі `Food`
Конструктор кидає відповідні винятки при порушенні доменних правил:
- порожня назва страви
- вага ≤ 0
- калорійність < 0
- білки < 0
- тип прийому їжі не в діапазоні 1–4

#### 3. Обробка винятків у `Main`
- `try-catch-finally` з гарантованим закриттям `Scanner`
- кілька `catch`-блоків (від специфічних до загальних)
- `multi-catch` для споріднених винятків
- **re-throw**: часткова обробка в `readFood()` + прокидання далі
- окрема обробка при пошуку зразка
