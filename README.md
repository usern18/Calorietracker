# Лабораторна робота 1: Реалізація консольного застосунку мовою Java

## Предметна область
Тема проєкту: **Облік спожитих калорій**.
У програмі реалізовано сутність **«Прийом їжі / Страва»**, яка описується п'ятьма характеристиками різних типів:
- `mealName` (`String`) — назва страви.
- `weightGrams` (`double`) — фактична вага порції у грамах.
- `caloriesPer100g` (`double`) — енергетична цінність на 100 грамів продукту.
- `proteinPer100g` (`double`) — вміст білків на 100 грамів продукту.
- `mealTypeInt` (`int`) — числовий код типу прийому їжі (1-4).

## Інструкція запуску через CLI
